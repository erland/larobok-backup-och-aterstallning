# Källpolicy

Prioritera officiella specifikationer och dokumentation, originalkällor till arkitekturmönster, erkända standarder samt leverantörsoberoende teknisk litteratur. Dokumentera versions- och konfigurationsberoende påståenden med datum och produktversion. Jämför minst två källor för kontroversiella eller centrala garantipåståenden. Skilj på dokumenterad funktionalitet, rekommenderad praxis och konstruerade exempel. Ange källor i referensregister och vid behov i text; kontrollera att länkar är aktuella före publicering. Låt inte enskilda molnleverantörers implementationsval framstå som universella principer.

Källområden att bearbeta: NIST SP 800-34 och SP 800-209; ISO 22301 och 27031 (om licensåtkomst finns); dokumentation för PostgreSQL PITR, Apache Kafka och RabbitMQ durability/recovery; Kubernetes och CSI snapshots; transaktionsoutbox, saga, idempotens och event sourcing. Inga specifika utgåvor eller tekniska garantier påstås verifierade i detta planeringssteg.
