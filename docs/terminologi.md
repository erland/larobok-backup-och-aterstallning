# Terminologi

- **Backup / säkerhetskopia:** Bevarat återställningsunderlag.
- **Restore / återläsning:** Teknisk operation för att läsa tillbaka underlag.
- **Återställning:** Hela processen till verifierat användbart tillstånd.
- **RPO:** Accepterad maximal dataförlust uttryckt som tid.
- **RTO:** Accepterad maximal tid till återupptagen förmåga.
- **Replay / återspelning:** Återbearbetning av bevarade händelser; kan skapa sidoeffekter.
- **Idempotens:** Upprepad operation ger samma avsedda effekt.
- **Konsistens:** Specificera alltid vilken regel och systemgräns som avses.
