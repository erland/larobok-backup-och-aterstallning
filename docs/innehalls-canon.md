# Innehållscanon

Grundtes: En lyckad teknisk restore garanterar inte korrekt verksamhetstillstånd. Återställningsförmåga beror på arkitektur, datamodell, meddelandehantering, drift och avstämning med externa system. Monolitisk backup framställs inte som felaktig; jämför systematiskt förutsättningarna. Replay får inte återutlösa externa effekter. Replikering ersätter inte backups. Begreppen datakonsistens, verksamhetskonsistens och operationell återstart hålls åtskilda.
